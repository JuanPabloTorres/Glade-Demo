# Pattern catalog

## New page
Start with a flow spec, compose shared layout/header/state components, use typed API clients and i18n, and add responsive/a11y evidence.

## New Flowbite control
Inventory duplication, add a semantic wrapper in the shared component layer, define states and tests, then migrate call sites incrementally.

## New API operation
Registry → generated contract → DTO/service/router/tests → frontend client. Never place endpoint strings in pages.

## New assistant action
Add structured schema and allow-list mapping, authorize context, localize label/icon through registries, apply guardrails and test invalid/cross-case behavior.

## Parallel initiative
Create integration branch and registered worktrees. Each stream owns paths and creates a change fragment; integration-manager owns shared files and version.
