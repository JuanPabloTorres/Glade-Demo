# Documentation instructions

Actualiza documentación cuando cambie comportamiento, arquitectura o entrega.

- Flujo nuevo: `docs/flows/<name>.md` antes de implementar.
- Decisión transversal: ADR en `docs/decisions/`.
- Cambio visible: demo script, capturas y aceptación UI.
- Cambio API: contratos y `docs/API-CONTRACTS.md`.
- Cambio de release: change fragment, versión y `RELEASE_NOTES.md`.
- Describe limitaciones con honestidad; no conviertas planes futuros en capacidades actuales.
