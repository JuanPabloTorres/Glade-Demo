# Five-Minute Demo Script

1. Explain the problem: client facts arrive from several sources and disagree.
2. Create a new immigration or bankruptcy matter.
3. Complete the intake with a canonical name and address.
4. Add a synthetic document whose name or address differs.
5. Show extracted facts and the conflict generated automatically.
6. Resolve the conflict explicitly and show the audit timeline.
7. Open Readiness and explain why the score changed.
8. Open API Docs and show the shared operation IDs and DTOs.
9. Close with the provider factory: deterministic today, replaceable with an LLM/OCR provider later.
