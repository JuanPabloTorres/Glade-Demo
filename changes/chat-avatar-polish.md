# Summary

Replace the undersized text placeholders in chat avatars with governed user
and assistant icons, improve bubble spacing and hierarchy, and keep the newest
message fully visible inside the transcript without scrolling the document.

# User-visible behavior

- “You/Tú” is no longer squeezed into a 24px placeholder or visibly cropped.
- The assistant uses the product gradient and sparkle icon; the user uses a
  distinct neutral profile avatar. Both expose localized accessible names.
- Message metadata wraps safely, long text breaks inside the bubble, and the
  copy action aligns with the message origin.
- On short phones, the latest message begins below the panel header instead of
  leaving half of the preceding avatar at the transcript edge.

# Migration / compatibility

No API, persistence, assistant-provider, or locale contract changes. Existing
message data and copy behavior remain compatible.

# Tests and evidence

- 147 frontend unit tests pass, including the icon-avatar regression.
- 10 focused Playwright assistant tests pass with isolated API/web servers.
- Rendered and captured at 320, 390, 768, 1024, and 1440 in Spanish, plus
  English at 390; avatars measure 36x36, the newest avatar is fully visible,
  the composer stays in view, document scroll is stable, and console/overflow
  checks are clean.
- Evidence: `frontend/test-results/chat-avatar-evidence/` (ignored runtime
  artifacts generated by the Playwright spec).
- Flowbite governance, locale parity, lint (0 errors), and production build
  pass.

# Risks / limitations

Older messages can naturally leave the scrollport as the conversation grows;
the most recent message is the stable reading anchor. Existing repository lint
warnings and the documented bundle-size warning are unchanged.
