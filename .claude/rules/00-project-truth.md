# Project truth

FreshStart es un workspace bilingüe de preparación de bancarrota para cliente y abogado con datos sintéticos. No determina elegibilidad, no selecciona capítulos y no sustituye revisión profesional. El frontend es React/Vite/Flowbite; el backend es FastAPI y hoy es mayormente stateless. RuleBasedProvider es el fallback confiable; Ollama no puede inventar hechos ni ampliar su autoridad. `contracts/api-contracts.json` es la fuente de verdad de operaciones.
