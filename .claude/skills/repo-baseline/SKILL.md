# Repository baseline

1. Record branch, HEAD, status, version, remotes and worktrees.
2. Read `CLAUDE.md`, nested instructions, contracts, product blueprint, architecture and recent decisions.
3. Inventory routes, features, services, providers, tests and deployment files relevant to the request.
4. Run read-only checks; never treat old audits as current proof.
5. Classify evidence as Verified, Partial, Missing, Contradictory or Live-unverified.
6. Save the baseline in the task manifest before editing.
