# Plan change

Document current behavior, target behavior, affected boundaries, file ownership, data/API changes, UI states, security, migration, rollback, tests and evidence. Prefer the smallest coherent implementation. A new dependency, persistence strategy, auth model or transversal abstraction requires an ADR before implementation.
