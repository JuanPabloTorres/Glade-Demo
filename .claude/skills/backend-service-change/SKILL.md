# Backend service change

Inspect current service patterns. Put orchestration in services, HTTP concerns in routers, typed data in Pydantic DTOs and provider variability behind protocols. The current backend is mostly stateless; persistence needs an ADR and explicit repository implementation. Add unit, API, authorization and negative-path tests.
