# Visual QA

Exercise affected journeys at 1440×900, 1024×768, 768×1024, 390×844 and 320×720. Check hierarchy, labels/icons, actions, loading/empty/error states, no overflow/overlap, keyboard/focus and contrast. Capture screenshots from the integrated tree. A passing build is not visual approval.
